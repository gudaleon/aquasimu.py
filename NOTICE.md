aquasimu is a Python implementation of ideas published for the AQUASIM aquatic
system simulator (Peter Reichert, Eawag). AQUASIM is described in Reichert
(1994) Water Science and Technology 30(2):21–30 and in the AQUASIM user manual.

The AQUASIM 2.1g source distribution posted by Eawag has no licence file, and
Eawag has not answered a licence query. This repository therefore contains no
Eawag source, no AQUASIM binary, no `.aqu` example and no AQUASIM listing.
Numeric kernels that AQUASIM bundles from netlib (DDASSL, LINPACK and related
routines) are not copied from that distribution.
