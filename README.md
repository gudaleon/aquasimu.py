# aquasimu.py
Python port of AQUASIM (Eawag/Reichert) aquatic system simulator: all compartments (mixed, biofilm, advective-diffusive, soil, river, lake), mass-balance checks, PEST++ and DREAM calibration.

## Archive branch

The branch `archive/bioreactor-prototype-AN-v1` adds the box working trees under
`prototypes/` and the port plan plus modelling-section drafts under `docs/`.
See `NOTICE.md` and `prototypes/README_AN_v1.md`. The BioWEN-P port in
`prototypes/biowenp_py_AN_v1/` is LGPL-3.0-or-later (Zhou et al. 2023).
The installable aquasimu package is developed on pull request #1.
